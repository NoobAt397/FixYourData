## 🚀 HOW TO USE (Step-by-Step)

### Step 1: Create Profile
1. Open the app
2. Click **"✨ Create New Profile"**
3. Enter your name (e.g., "Player1")
4. Click **"✅ Create & Continue"**

### Step 2: Game Setup (Auto-Shows!)
After creating profile, you'll AUTOMATICALLY see:
- **"⚙️ Game Settings"** panel
- Starting gold input (default: 100)
- Big blue **"✨ Launch Game!"** button

### Step 3: Launch Game
1. Adjust starting gold if you want (or leave at 100)
2. Click **"✨ Launch Game!"**
3. **BOOM!** Dashboard appears with:
   - 3 tabs (Game Play / Statistics / Management)
   - Turn executor
   - Countries table
   - All features unlocked!
